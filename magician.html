I · The Magician of the Compass

Lapidary · narrow function · user-initiated
Tarot · The Magician Instrument · Compass Scope: narrow Initiative: user
"Unum bene" — "One thing, well."

What kind of AI agent

A single function call. The user names the operation; the system performs it precisely and stops. No state across calls, no scope creep beyond the named operation.

The Tarot archetype

The Magician channels intent through chosen tools. He stands between heaven and earth wielding the four suit-objects — the card of deliberate craft: a single intent, a single instrument, a clean act. Mastery here is not in knowing many tools but in choosing the right one for the moment.

The scientific instrument

The compass — a drafting and mathematical instrument used by Newton, Galileo, and every architect since Vitruvius. It establishes geometric precision through a single fixed point and an arc. The compass turns intent into measurable form, and only one form per setting.

Real-world examples

  • GitHub Copilot's inline ghost-text completing one line.
  • A citation-DOI lookup returning one entry.
  • Wolfram Alpha solving one expression.
  • Format-on-demand commands; unit converters; one-shot LLM calls with a fixed schema.

Strength

Trivially auditable. Predictable. The cleanest case for trust because the surface is small.

Signature failure mode

Brittleness. The Magician only works when you already know which tool to pick and how to wield it. Outside the operation's frame the instrument is silent — useless if you cannot name the spell, dangerous if you mis-name it.

Philosophical commitment

Heidegger's zuhanden — the ready-to-hand tool that withdraws from your attention in skilled use (Being and Time, §15). When the operation is well-chosen, the tool disappears into your action. Alongside Mollick's "centaur" working pattern in its quietest, most disciplined form: a clean division of labor where the system handles the well-defined operation and the human supplies intent.

The kind of co-scientist that fits you

A library of small precise tools, each well-named, each doing one thing reliably. You don't want a generalist agent; you want the right wand for each task. The system surface should be small enough to audit at a glance, deterministic enough to test, and silent enough to disappear when you're working.
